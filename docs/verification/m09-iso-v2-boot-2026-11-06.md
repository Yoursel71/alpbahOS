# M09 — first boots of the script-built live ISO (2026-11-06)

ISO: `scratch-lfs-bench/alp-iso-v2-20261106/alpbahos-live-20261106.iso` (2.6 GB), built by `scripts/lfs-blfs/live-iso/build-iso.sh` from the 12.4 rootfs (see [m11-fix02-root-cause-2026-11-06.md](m11-fix02-root-cause-2026-11-06.md)).

## Boots (BIOS / SeaBIOS, QEMU/KVM, `-m 4096 -smp 4 -cdrom <iso> -vga virtio -display none -serial file:…`)

| # | VM CPU model | Result |
|---|---|---|
| 1 | default (`qemu64`, baseline x86-64) | Kernel and dracut `alplive: kok overlay hazir` at 1.43 s; 0 `FAILED` units; serial `alpbahos login:` at ~14 s. The autologin Plasma session crashes: `kwin_wayland` killed by **SIGILL** (audit type 1701, `sig=4`) repeatedly, then drkonqi/plasmashell abort; SDDM greeter shown (screenshot). Log: [m09-iso-v2-bios-serial-2026-11-06.log](m09-iso-v2-bios-serial-2026-11-06.log), screen: [m09-iso-v2-bios-screen-2026-11-06.png](m09-iso-v2-bios-screen-2026-11-06.png) |
| 2 | `Nehalem` (x86-64-v2) | Same: `kwin_wayland` SIGILL ×7, `wireplumber` SIGILL ×1. Log: [m09-iso-v2-bios-nehalem-serial-2026-11-06.log](m09-iso-v2-bios-nehalem-serial-2026-11-06.log) |
| 3 | `host` (Ryzen 7 5700), **UEFI** (OVMF, q35, fresh VARS) | `efi: EFI v2.7 by EDK II`; `alplive: kok overlay hazir` at 1.59 s; 0 `FAILED`; 0 SIGILL; login prompt at ~14 s; the Plasma Wayland session starts and the desktop is usable. The live desktop is still stock KDE: Breeze wallpaper, default KDE panel, English UI and the KDE Welcome Center saying "Linux From Scratch" — the alpbahOS profile (D114, D115, D120, D121) is not installed in this rootfs yet. Log: [m09-iso-v2-uefi-hostcpu-serial-2026-11-06.log](m09-iso-v2-uefi-hostcpu-serial-2026-11-06.log), screen: [m09-iso-v2-uefi-hostcpu-screen-2026-11-06.png](m09-iso-v2-uefi-hostcpu-screen-2026-11-06.png) |

Conclusion: some libraries in the rootfs use instructions above x86-64-v2 without runtime dispatch. Earlier QEMU sessions passed because they used a host-like CPU. This breaks the old-PC target (D135). Investigation: [sigill-cpu-baseline-2026-11-06.md](sigill-cpu-baseline-2026-11-06.md) (in progress).

Other findings from boot 1:
- The SDDM greeter is English with keyboard layout `us`; D120 asks for Turkish UI and Turkish Q at the greeter too.
- The greeter uses the default SDDM theme (no alpbahOS branding yet).

Boot 3 confirms the crash depends on the CPU model: with the host CPU the same ISO runs Plasma. UEFI boot of the ISO works (boot 3).
