1. `grub-install` failed (GRUB had no libdevmapper): `grub-dm-2.14`.
2. `root=PARTUUID=` empty on a dm-crypt root: `alpbahos-grub10-r50`.
3. After the GRUB prompt Plymouth asked for the passphrase a second time: Calamares writes `none` as the key in `crypttab` and adds `rd.luks.key` only for a separate unencrypted `/boot`. `target-initramfs.sh` now points `crypttab` at the key file and stores `rd.luks.key` in the initramfs (`kernel_cmdline`).
