The round 45 PRINT coredump (systemsettings SIGABRT) was the test helper: `r21m-as-user` did not pass
`QML2_IMPORT_PATH`, so Kirigami was not found ("module org.kde.kirigami is not installed"). Fixed in 0697a1c; this
row is the first with the fix. Opened through KIO in a real session the page worked in round 45 too.

Round 47's own Welcome row failed for two harness reasons, not the image: the short run made no BIOS install, so
the VM had no disk ("window at: not found"), and the round 25 row looks for the old design's window colour and card
positions, so it cannot find design 4. A first rerun on the r47x install also failed at the greeter because that
install had a generated password, not the r21 test password the Welcome rows type. The new W4 row replaces the round 25
row for design 4.

Still open: `lpinfo --include-schemes dnssd -v` is empty (the printer is found by avahi and ippfind); the printer page
shows a hint that `system-config-printer` is not installed; boot timing: a back-to-back check of the round 43 and
round 45 installs (6 boots) followed the host load (load 2-5: 4.5-6.4 s to the greeter, load 15-20: 12-13 s), so the
round 45 timing row (5.0/5.3 s) is within host noise, not a measured regression. Not run on real hardware.
