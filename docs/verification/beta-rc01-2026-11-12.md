## 3. Deviations and notes

- **I1 manual click.** The installer's confirm button moved with INSTALLER-UI-01; the lane clicked its edge. The reviewer
  clicked 748,455 once by QMP; I2, KF and F1 then ran with the fixed harness (`r20-lanes.sh`, `matrix-r21.sh`).
- **Base.** The snapshot is the live r4-root as instructed, so rc01 also carries what the other session recorded there
  after the r40 ISO (firmware dir links, kutu records, pm hint, calamares-r41, libglvnd 1.7.0, mesa-glvnd 26.1.7).
- **alp.py** of 58524f5 also contains ALP-FLATHUB-01 and ALP-KUTU-01; the Flathub part works (APPS, U1), the kutu part
  fails for lack of netavark (KUTU).
- **Live initramfs has no plymouth**, so the plymouth fix only matters on the installed system; S1 and PLY test it there.
- **Harness slips (no effect on verdicts):** `SBX-units.txt` printed "coredumps: command not found" (a `;` inside the
  echo in `rc01-queue.sh`); the coredump count is in `SBX-final.txt` (0). `alp-check.sh` prints a `printf` write error
  when its output is cut by `head`.
