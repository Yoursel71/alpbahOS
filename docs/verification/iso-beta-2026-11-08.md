`nvme-core.ko`, `virtio_scsi.ko` are in the image; `sd_mod`, `virtio_blk`, `ext4`, `vfat` are built into the kernel
(`modules.builtin`), so they are not files in the image.

UEFI autologin repeatability (item 4): three consecutive UEFI live boots of the final ISO autologged (runs
final-uefi-live-1, -2, -3). The earlier failures (live runs on build 2 and build 4) had no explanation; the
present behaviour is consistent across three boots.

Live without LIBGL (item 3): Plasma comes up with autologin and the desktop renders without
`LIBGL_ALWAYS_SOFTWARE=1` on QEMU virtio VGA (the GL renderer was not checked). The variable is removed from the ISO. The build keeps it only with
`LIBGL=1` (not used for the final ISO).
