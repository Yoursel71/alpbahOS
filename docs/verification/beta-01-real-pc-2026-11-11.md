# BETA-01: first real-PC test, 2026-11-11

The first run of alpbahOS on real hardware. ISO `alpbahos-beta-0.9-2026-11-09-r39.iso` (sha256
`d506be0c97f1ec5e5ad2781d4a43da3b26262735d1acce8a1f73c72d35fbc240`) on a SanDisk Cruzer Blade USB stick (written by
Claude with the user's approval and compared byte for byte, [round 39](round-39-2026-11-11.md)). The user ran the test;
results come from the user's answers to 20 questions (asked with the question tool) and from the journal of the
installed system, read by Claude read-only from Fedora afterwards (`/dev/sda2`, boot 4022cd8e, 20:19:47-20:28:46).

Hardware: the user's desktop (hostname of the install `alpbahos-b450mhdvr40`): ASRock B450M-HDV R4.0, AMD Ryzen 7 5700,
NVIDIA RTX 5060 (no proprietary driver in the image), 2 TB of disks: NVMe with Fedora (untouched), SATA HDD (install
target, free space next to an existing ext4 partition), SATA SSD (empty), UEFI, Secure Boot off, wired network.
