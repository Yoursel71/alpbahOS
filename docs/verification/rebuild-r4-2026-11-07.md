## 2. Method

- Build root `scratch-lfs-bench/r4-root`: writable btrfs snapshot of `r3-root` made after TEMP-01 and the
  alp upgrade (both in place).
- Per package (`scripts/rebuild/r4/run-r4.sh`):
  1. Source: BLFS 13.1 URL, cached in `scratch-lfs-bench/blfs-src-13.1`. The MD5 on the book page must match.
     No upstream sha256 is published on these pages, so the sha256 is recorded as TOFU.
  2. Script: the test image's generator (`blfs-plan/gen_blfs_chroot.py`) writes the 12.4 commands. The
     12.4 version strings are replaced by the 13.1 ones (`subst`), and per-package deltas from
     `scripts/rebuild/r4/deltas/` are inserted or substituted. The generated script starts with
     `export LANG=C LC_ALL=C`.
  3. Chroot build with `make install` straight into the root (no DESTDIR: the fallback method).
  4. Read-only snapshots before and after, `r3_ledger.py diff`, manifest (`r4_lib.py manifest`).
  5. Ownership transfer (`r4_lib.py transfer`, last writer owns): paths the package rewrote are taken from
     the earlier record; a base record with the same name is replaced, and its files the package did not
     rewrite go to a `<name>-<oldversion>-leftover` record. Moves are logged in `r4-ledger/transfers/moves.tsv`.
  6. `alp adopt-base` on `r4-root` (records are `lfs-base` and protected: a deviation from D141 until real
     DESTDIR recipes exist).
  7. ISA audit (`audit-isa.sh`) on the new ELF files.
- A failed try keeps its diff; the next try removes the files it added (the book's `ln -s` can then run).
