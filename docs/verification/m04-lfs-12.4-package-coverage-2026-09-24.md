# M04 LFS 12.4-systemd Chapter 8 package coverage — 24 September 2026

## Scope and result

This matrix compares the official LFS 12.4-systemd Chapter 8 package list with
the staged manifests currently committed under
`manifests/lfs-base/`. The official chapter contains 79 package entries.
There are 36 staged package manifests, covering 11,321 recorded paths. These
are controlled `DESTDIR` install trees, not historical records of how the
current `/mnt/lfs` rootfs was installed. A separate read-only Builder source
cache audit found all 57 packages that were missing manifests at the time had
a candidate source archive at `/mnt/lfs/sources/` root; thirteen have since had
source hashes verified for stage capture, leaving 44 without manifests.
Archive presence is not checksum or build evidence; each package source still
must be checked before use. The live
`/mnt/lfs/var/lib/alp/db.json` still has an empty `packages` object.
Accordingly, no row below is marked as an installed ownership record.

“Rootfs comparison” is a read-only comparison of a staged manifest to the
current rootfs. A full match only establishes that the compared manifest paths
match at the time of comparison; it does not independently prove that package
was the historical installer. Coreutils' special Chapter 6 bootstrap
comparison is not a final-system comparison.
