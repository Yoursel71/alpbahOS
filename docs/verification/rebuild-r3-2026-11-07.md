# REBUILD-R3: base packages recorded through alp (2026-11-07)

Status: **Done** for the acceptance in BACKLOG (every base package has an alp record; the ownership
check passes; no unowned base files). `/mnt/lfs13` is not replaced; `r3-root` is kept for the
coordinator's decision.

Decision quotes:
- D141 (docs/DECISIONS.md): "During the rebuild every base package is installed through `alp`,
  so the file-ownership ledger is created automatically. This closes the v1 D34 debt."
- D122: "Package engine: `alp`."

## 1. Method

1. `scratch-lfs-bench/r3-root` is a writable btrfs copy of `lfs13-snapshots/after-ch7-2026-11-06`
   (the state before ch8). `lfs13-snapshots/before-r3-2026-11-07` (read-only) was taken before any change.
   `/mnt/lfs13` was only read (dry run compare, classification, deep checks).
2. Each chroot step ran on `r3-root` with `scripts/rebuild/run-chroot.sh` (R3 options: `R3_ROOT`,
   `R3_LOGROOT`, `R3_SKIP_TESTS`, `R3_TEST_KEEP`, `R3_BODY_FILE`). A read-only pre/post snapshot pair
   gave the exact changed paths (`scripts/rebuild/r3/r3_ledger.py diff`: ctime, size, mode, owner,
   symlink target). One snapshot was kept at a time.
3. Owner of a path = the last step that wrote it (`r3_ledger.py owners`). A later delete releases it.
4. The chapter 5-7 leftovers (files no chapter 8+ step wrote) are split by origin and by a
   documented rule (`r3_ledger.py split-leftover`, section 3).
5. Manifests (format `alpbahOS.package-files/v1`) are generated from the final state of `r3-root`
   and adopted with `alp adopt-base`, with the source sha256 and the manifest sha256.
6. The alp prototype is installed into `r3-root` as step `zz-alp` (`/usr/lib/alp/alp.py`, `/usr/bin/alp`).

Test steps: skipped (`R3_SKIP_TESTS=1`, shim `scripts/rebuild/r3/test-skip-shim.sh`) except for the
scripts whose own gates count test results: `03-glibc`, `20-binutils`, `21-gmp`, `31-gcc`, `53-python`,
`73-vim`, and `22-mpfr` in its re-check step ch08-31b.

## 2. Steps and deviations

- 94 chroot scripts ran (ch8 82, ch9 3, ch10 8, ch11 1). `ch8/00-glibc-lib32-conf.sh` is not run: its
  header says it is a repair step for an existing root, and `03-glibc.sh` contains the same step.
- **MPFR (ch08-22).** Its test gate needs 198 PASS, 0 SKIP, 0 FAIL, but the chapter 6 libgcc has no BID
  objects until GCC is rebuilt (R2 note CH6-LIBGCC-BID). ch08-22 built and installed MPFR with the
  gate removed (`r3/22-mpfr-notest.sh`, the book script without lines 25-38). **The gate was deferred,
  not passed.** The full script ran again after GCC as **ch08-31b**:
  `mpfr: '# PASS' total=198, '# SKIP' total=0, '# FAIL'+'# ERROR' total=0`. The SONAME is
  `libmpfr.so.6`, unchanged, so MPC was not rebuilt. `libmpfr.so.6` is byte-identical to the R2 tree.
- **Out-of-book tarballs** (cpio 2.15, dracut-ng 112) are not in the book md5sums. The ledger accepts a
  local tarball only when its sha256 starts with the 20-digit prefix recorded in R2
  (`rebuild-r2-ch9-ch10-2026-11-07.md`). No upstream signature was checked (as in R2).
- **Host-staged inputs** that R2 had staged in `/mnt/lfs13/sources` were copied, not built, into
  `r3-root/sources` (`config-fedora-7.2.7-200.fc44`, `cpio-2.15.tar.bz2`, `dracut-ng-112.tar.gz`,
  `kvm-emulate-host-avx-gate.patch`). `/sources` is not part of the base.
- **alp validator (section 4).** Backslashes are now allowed in manifest paths. The systemd escaped unit
  name `system-systemd\x2dmute\x2dconsole.slice` is a real POSIX name. NUL, line breaks, relative paths,
  empty, `.` and `..` segments and `/var/lib/alp` are still refused. Tests: 264 passed in the alp
  prototype suite (`docs/handoffs/claude/alp-prototype/tests`), including the new accept and reject cases.
