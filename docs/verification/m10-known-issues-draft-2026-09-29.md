# alpbahOS 0.2-alpha known issues (draft)

This draft incorporates live PackageKit and UEFI evidence from 30 September 2026. It is not a final alpha release approval.

| Area | Current limitation | Status / evidence |
|---|---|---|
| Wallpaper | Older HDA candidate rendered black/missing wallpaper. | **Improved on the current trial ISO:** 30 September UEFI/1920×1080 screenshot shows Atatürk background in the guest. Full wallpaper/theme quality acceptance remains open. See [deployment audit](m09-wallpaper-deployment-audit-2026-09-29.md) and current [M08/M10 runtime evidence](m08-live-packagekit-auth-runtime-2026-09-30.md). |
| VirGL rendering/performance | Latest 153622Z ISO booted Plasma under QEMU SDL/OpenGL `virtio-vga-gl`; 1920×1080, Konsole input, visible pointer, and QEMU GPU graphics-client allocation were observed. The GTK EGL frontend still aborts at host startup; no quantitative FPS/latency benchmark exists. | **PASS (SDL/OpenGL rendering smoke), benchmark OPEN.** No PCI passthrough claim. See [VirGL SDL report](/mnt/alpbahOS-data/alpbahOS-build/m06-m10-progress-20260929/m09-virgl-sdl-20260929/m09-virgl-sdl-2026-09-29.md). |
| Package install/remove | PackageKit CLI install/remove passes on `m10-pk-sim-helper`. Discover GUI install added htop; GUI remove removed it, but also displayed a generic “Update Issue” error. Discover still renders package size as `16.0 EiB`. | **PARTIAL.** CLI transaction passes. Discover reports failure after performing removal, so its transaction feedback remains open; unknown size rendering and catalog signature verification also remain open. See [live-auth and Discover retest](m08-live-packagekit-auth-runtime-2026-09-30.md). |
| KDE store startup/feed | Home cards and htop result/detail rendered in current-image VMs; the latest run still showed `Loading…` after 35 seconds before the later search succeeded. | Intermittent startup remains unexplained; same-ISO DNS/HTTPS passed. See [networked GUI retest](m08-discover-networked-live-2026-09-29.md) and [transaction probe](m08-package-store-transaction-failure-2026-09-29.md). |
| Discover package size | Htop's detail page shows `16.0 EiB` although package size is unknown. | The PackageKit helper emits its unknown-size sentinel; Discover renders it as a literal huge size. Do not infer a real package size. Correct rendering is open. See [networked GUI retest](m08-discover-networked-live-2026-09-29.md). |
| Graphical authorization | The live-only Polkit rule grants the active local `alpbahos` user the selected PackageKit catalog actions without a password. It must not be shipped in a persistent installation. | **PASS for scoped volatile live actions; other admin actions remain locked.** Catalog signature verification remains part of the open M10 security review. See [live-auth runtime report](m08-live-packagekit-auth-runtime-2026-09-30.md). |
| Live privilege bits | The current SquashFS contains 19 root-owned setuid files and one root:tty setgid file; merged OverlayFS honors these bits. | Two 2D read-only-ISO runtime probes confirmed identity/modes, invalid-PID `newuidmap` rejection, arbitrary tmpfs mount denial, `su` password rejection, Polkit cancellation denial, and loopback ping. The current kernel disables `CONFIG_USER_NS`, so newuidmap/newgidmap valid-map behavior is untestable on this image. Most helper/policy paths remain open. See the [numeric inventory](m09-setuid-sgid-inventory-2026-09-29.md) and [risk draft](m09-setuid-sgid-security-review-draft-2026-09-29.md); these are not security approval. |
| SquashFS xattrs | Earlier M09 kernel ignored SquashFS xattrs. | Fixed in the new `m09-live-audio-xattr` kernel profile; BIOS/UEFI serial logs are clean and guest `getfattr` read a SELinux label. See [kernel report](m09-xattr-enabled-kernel-2026-09-29.md). |
| Spectacle GUI | Region selection, editor and GUI save succeeded; guest listed a 15,170-byte PNG. Pixel dimensions/content were not independently checked. | Passed on the 072542Z HDA candidate; see [GUI capture/save report](m07-spectacle-gui-save-2026-09-29.md). |
| Live-media sanitizer | The predecessor ISO contained empty root-owned `/home/sa` and `/home/tester` directory entries. | Fixed in 085919Z SquashFS; new 090347Z ISO passed BIOS/UEFI boot smoke. See [xattr/sanitizer report](m09-xattr-enabled-kernel-2026-09-29.md). |
| Desktop services | Konsole showed D-Bus `ServiceUnknown` / UDisks2 warnings during the guest session. | They did not prevent the tested Okular/Gwenview file views or Spectacle CLI output. Root cause remains open. |
| Keyboard layout | Turkish glyphs render in Konsole; system locale is `tr_TR.UTF-8` and virtual-console keymap is `trq`. The live Wayland layout and physical Turkish-Q key sequence were not interactively validated. | The RFB/VNC keystroke path is not host keyboard acceptance. |
| Physical devices | Physical Wi-Fi, Bluetooth pairing, audio input/output, and broad GPU support are not validated. | Virtual NIC/controller and loopback audio evidence must not be presented as physical-device acceptance. |
| ABI | This alpha is x86_64 / 64-bit only. | Long-term 32-bit x86 runtime/multilib remains accepted, scheduled for separate M03/M04 work after the 64-bit M06–M10 alpha. |
| Package ownership | LFS Chapter 8 ownership is reconciled from the D34 event ledger, including a separate supplemental Linux-PAM replay. | **PASS for historical package ownership evidence:** official LFS 12.4 Chapter 8 79/79 packages; this does not prove final M09 rootfs or ISO acceptance. See the D34 ledger and [current status](../../CURRENT.md). |

See the [M10 alpha matrix](m10-alpha-test-matrix-2026-09-29.md) for test scope and acceptance state.
