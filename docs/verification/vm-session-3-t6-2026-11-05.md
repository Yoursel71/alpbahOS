# QEMU VM oturumu 3 — T6 uygulama varsayılanları (5 Kasım 2026)

Onay: kullanıcı "VM testleri yapabilirsin, kabul" dedi. Tek açılış, ~1 saat. Ortam: `disk-blfs3.img` + T6 payload (Okular, Ark, Kate/KWrite, Gwenview, poppler, exiv2, libkexiv2, qtimageformats) + `/etc/xdg/mimeapps.list` (`profiles/apps/generated/mimeapps.list`).

## Sonuçlar

| Kontrol | Sonuç |
|---|---|
| `gio mime application/pdf` | Varsayılan `okularApplication_pdf.desktop` — **GEÇTİ** |
| `gio mime text/plain` | Varsayılan `org.kde.kwrite.desktop` — **GEÇTİ** |
| `gio mime inode/directory` | Varsayılan `org.kde.dolphin.desktop` — **GEÇTİ** |
| Okular açılır (PDF) | `okular test.pdf` Wayland ortamında doğrudan başlatıldı, süreç sayısı 1 — **GEÇTİ** |
| KWrite açılır (metin) | `kwrite test.txt` Wayland ortamında doğrudan başlatıldı, süreç sayısı 2 — **GEÇTİ** |
| `gio open` ile varsayılan açılış | Okular xcb eklentisine düşüp başlamadı (DBus etkinleştirme ortamında WAYLAND_DISPLAY yok) — **KISMİ**. Varsayılan eşlemesi doğru; açılış yolu DBus etkinleştirme ortamına bağlı, ayrıca incelenecek |

Oturum: `alpbah` Plasma oturumu, greeter'a QEMU monitörü ile şifre girildi (oturum geçici şifresi, repoda yok). `xdg-mime` / `xdg-open` VM'de kurulu değil; `gio` kullanıldı.

## Açık

1. `gio open` / DBus etkinleştirme ortamında Okular'ın Wayland ile başlaması (`WAYLAND_DISPLAY` DBus servis ortamına geçmiyor). Çözüm adayı: `dbus-update-activation-environment` ya da Plasma oturumunda `systemctl --user import-environment`.
2. `xdg-utils` paketi yok; T6 kabulü için `xdg-open` gerekiyorsa eklenmeli.
3. Gwenview ve Ark için MIME kontrolü yapılmadı (T6 kabulü için zorunlu değil).
