- Tooling lessons: never rewrite a script in place while a job runs it (bash reads scripts as it goes; a Python
  `open(..., "w")` rewrite of `build-pkg-r10.sh` broke a running NSS step); `pgrep -f` inside a monitor command
  matches the monitor's own shell (wait on a PID instead); in a chroot of r4-root, `alp` needs `/proc` mounted for gpgv;
  the chroot's `/dev` is a plain bind, so `/dev/shm` must be mounted for builds that use POSIX semaphores.
